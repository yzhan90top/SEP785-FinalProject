🏀 NBA Shot Success Prediction Project
This project aims to build a machine learning model that predicts whether a basketball shot will be made or missed based on contextual and gameplay data. 
We will go through the complete pipeline from data preprocessing and feature engineering, to visualization, model training, and evaluation.
